# 欢迎来到立方世界！！！

# Welcome to Cube World!!!

## 介绍

服务器版本:Java 26.3
游玩版本:Java 1.9-26.3或基岩版Geyser支持的版本(注：基岩版游玩同步Java版特性)

服务器地址:
Java:
```
fn.mrhecloud.top:22007
```
基岩:
```
fn.mrhecloud.top:20008
```
验证方式：在线


----------

这里是一个充满冒险又富有创造的领域

你可以在这里体验农耕生活，或者探索世界，亦或是寻找挑战！

你也可以发挥你的想象力，建造各种建筑！
<!---
### 富有挑战

本服务器安装了Vic's Point Blank模组，你可以与伙伴们互相挑战；Alex的生物也让世界有更多可供挑战的生物

### 多彩多样

本服务器安装方块小镇以及夸克模组，在世界中你能发现各种新奇的群系，你也可以随心所欲修建家园
