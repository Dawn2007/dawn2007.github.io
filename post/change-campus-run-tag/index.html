更换校园跑标签内容

发表于2026-11-18|更新于2026-11-23|教程

说明

这个标签是2026年11月贴上去的，主要方便我们寝室的刷校园跑，考虑到我们搬走之后学校可能换小程序，我特此在这里放出更改这个标签内容的方法

步骤

准备

我用的标签是网上到处都是的NTAG216标签，成本极低，不过需要一台带NFC功能的手机(应该没有几个手机没NFC功能了，没有的话建议问同学借一个)

这里需要用到一个叫NFC Tools Pro的软件，下载链接附在下面
下载链接

复制标签

先去运动场复制一份数据
在运动场大门找到用来打卡的NFC标签

打开软件
切换到写选项卡，点击更多的选择(黄色标记)

接着点击从Tag标签导入记录(黄色标记)

把手机NFC感应区贴近标签
当软件读取成功就可以开始写入数据了
你也可以把这个数据保存下来，方便写入更多次，方法详见附录

写入数据

点击写(绿色标记)

把手机NFC感应区贴近宿舍的NFC标签
提示写入成功即可退出软件

测试

退出软件，将手机NFC感应区贴近标签
当手机成功弹出当前正在使用的校园跑小程序即操作成功

附录

附1 保存数据方法

保存数据

读取数据完成后，点击更多的选择(黄色标记)

点击保存标签配置文件(绿色标记)

点击新的配置文件，在输入框输入一个名称，点击OK即可保存

读取数据

切换到写选项卡，点击更多的选择(黄色标记)

点击从配置文件加载tag标签(红色标记)

选择你保存的配置文件，两个选项随便选
接着点击写(绿色标记)

即可使用保存好的数据
