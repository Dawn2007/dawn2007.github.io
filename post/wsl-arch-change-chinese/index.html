发表于2026-03-07|更新于2026-11-18|教程

本文参考了豆包

一、问题

在WSL中像普通Arch Linux一样切换中文后注销会发现语言依旧为英文

二、原因

1. WSL 默认会继承 Windows 的系统语言和区域设置，这会覆盖 Linux 内的 locale 配置。
2. 直接修改  /etc/locale.conf  或使用  localectl  往往不生效，因为 WSL 的初始化机制不同。
3. 中文显示和输入问题，通常需要同时配置 WSL 内部和 Windows 侧的设置。
